Summary

Join catalog

Every distinct join. Click a column header to sort. Open a row's uses to see each statement and line.

Conflicts

The same two tables joined on different columns in different places. One variant is often a bug.

Suggested views

Groups of joins that repeat together. Each draft view is text to check and copy; nothing was run.

Joins without a declared key

Joins the schema does not declare as a foreign key, in either direction.

Subquery links

Columns tied through IN, NOT IN, EXISTS or a correlated subquery. They are not joins, so the catalog, the views, the conflicts and the joins without a key leave them out; they still count for impact.

Unreadable

Files and statements that could not be read, and names whose table is not certain. Nothing is skipped silently.

Impact

Choose a table or a column (TABLE.COLUMN) to see every statement that uses it, and the tables downstream.
